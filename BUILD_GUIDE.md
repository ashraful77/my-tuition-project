## Build with Android Studio

1. Install the latest stable Android Studio.
2. Extract this ZIP.
3. In Android Studio choose **Open** and select the extracted `MyTuitionManager_BUILD_READY` folder.
4. Allow Gradle to download the required Android/Gradle components.
5. Wait for Gradle Sync to finish.
6. Select **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
7. Android Studio will show the generated APK location.
8. Copy the APK to your Android phone and install it.

## Important
This package is source code, not a precompiled APK. The Android SDK/Gradle build environment is required to produce the APK.

## Current features
- Offline student records
- Multiple batches
- Individual monthly fees
- Partial payments
- Current-month dues
- Payment history
- PDF fee receipts
- Android share sheet (including WhatsApp)
- Backup/restore
- Basic dashboard

## Recommended test
Before using real records:
- Add 2–3 test students.
- Give them different fees.
- Record full and partial payments.
- Generate a receipt.
- Share it to WhatsApp.
- Create a backup.
- Restore the backup on a test installation.
